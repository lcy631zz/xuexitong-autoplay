# 超星学习通 · 自动播放 + 播完自动下一节

一个 Tampermonkey / 脚本猫用户脚本，帮你免去「盯着一个视频播完再手动点下一节」的重复操作：

- 进入某节后**自动点播放**；
- 当前视频真正播完后**自动点右侧目录的下一节**并继续；
- 视频内弹出的【单选题】会**逐个尝试作答直到答对**（多选/填空不代答）；
- **默认静音播放**（浏览器普遍拦截带声自动播放，静音才稳），面板右侧 🔇/🔊 可一键切回有声。

> ⚠️ **声明**：本脚本仅用于脚本调试、前端自动化研究和页面行为分析，请遵守目标平台的使用规定。
> 视频按 1 倍速、在前台、真实播放完整时长，不加速、不绕过平台的防挂机检测。

## 安装与使用

详见 [安装与使用说明.md](安装与使用说明.md)（纯浏览器操作，不用写代码）。

## 功能边界

| 能做 | 不做 |
| --- | --- |
| ✅ 自动播放 / 播完自动下一节 | ❌ 加速（固定 1 倍速） |
| ✅ 弹题自动作答（仅单选） | ❌ 自动答多选/填空、过滑块验证码 |
| ✅ 默认静音播放，面板一键切有声 | ❌ 绕过平台检测 / 切走页面偷偷续播 |
